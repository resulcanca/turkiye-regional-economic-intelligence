# Power BI Spec
1. Overview: 2025 income, national average, top/bottom 5, growth.
2. Regional Ranking: bar chart + region slicer.
3. Income Gap: Ankara gap and % of national mean.
4. Housing: KFE/YKKE comparison for Istanbul/Ankara/Izmir.
5. Decision View: select region and show income, growth, rank, national percentile.
Use the CSVs in `data/` as import tables.
